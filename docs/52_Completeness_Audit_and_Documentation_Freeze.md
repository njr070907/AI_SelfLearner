## 3. 有意留到开发中完成的内容

以下不是文档缺口，而是必须通过实现或真实证据才能确定：

- 实际依赖版本、安装命令、运行命令和截图。
- 最终 SQL 迁移、API 细节和错误码。
- 真实模型选择、价格、延迟和供应商条款。
- 基于用户测试得到的评分阈值、Prompt 最优版本和学习效果。
- 生产域名、云平台、告警联系人和法律主体信息。

在没有代码和真实运行数据前继续细化这些内容，会制造虚假确定性。

# Personal Cognitive Model 设计

## 1. 目的

个人认知模型用于描述用户在特定证据范围内的知识状态、能力表现、思维模式和学习行为。它服务于更好的学习反馈，不是人格测验，也不是对人的永久定义。

> 数据描述用户在某些情境下的表现，而不是定义用户是谁。

## 2. 七层模型

### 2.1 Goals：目标层

- 当前目标、用途、期限、优先级；
- 用户为何学习以及成功标准；
- 目标的变化历史。

### 2.2 Knowledge State：知识状态层

每个概念记录：正确性、机制理解、应用、保持、最近证据、置信度。状态随证据更新，不等同于考试分数。

### 2.3 Abilities：能力表现层

在具体任务中观察的能力，例如抽象、分解、迁移、论证、实践。只能描述任务表现，不从一次失败推断稳定能力。

### 2.4 Thinking Patterns：思维模式层

跨多个领域重复出现的模式，例如把相关性当因果、快速抽象但忽略边界、擅长案例但缺少形式化。每个模式需要多条独立证据与反证。

### 2.5 Learning Behavior：学习行为层

频率、时段、会话长度、完成率、复测间隔、建议采纳情况。行为事实与动机解释必须分开。

### 2.6 Effective Preferences：有效偏好层

基于结果的偏好，例如“先看整体地图后再学细节时表现更好”或“案例后接定义更有效”。不采用缺乏证据的固定学习风格标签。

### 2.7 Confidence & Provenance：置信度与来源层

每个结论关联证据、反证、样本量、时间范围、来源、算法版本、用户反馈和置信度。

## 3. 证据单位

一条 `CognitiveEvidence` 至少包括：

- 发生时间与会话 ID；
- 概念和任务类型；
- 用户原始回答或行为事实；
- AI 观察及短证据片段；
- 参考标准或材料来源；
- 诊断置信度；
- 用户是否认可；
- 生成该观察的版本信息。

## 4. 状态与模式的区别

| 类型 | 示例 | 更新方式 |
|---|---|---|
| 事件 | 本次没有解释学习率作用 | 永久保留原始记录 |
| 状态 | 当前对梯度下降机制理解脆弱 | 同概念证据加权更新 |
| 候选模式 | 可能经常忽略参数边界 | 至少 2 条证据后出现 |
| 稳定模式 | 多领域任务中反复忽略适用条件 | 多源证据、反证审查、用户可确认 |

## 5. 更新原则

1. **渐进更新**：一次记录只产生有限影响。
2. **新近性**：近期证据权重更高，但历史不被直接覆盖。
3. **任务可比性**：不同难度、形式和领域不能直接平均。
4. **来源质量**：有参考答案和追问验证的证据权重更高。
5. **反证保留**：与结论冲突的证据必须可见。
6. **置信度与状态分离**：掌握估计高不代表证据充分。
7. **用户纠正**：用户反馈改变置信度，不删除原始事实。

简化更新可表示为：

```text
new_state = weighted(old_state, new_evidence)
confidence = f(sample_count, evidence_quality, consistency, recency)
```

不要把固定的 `旧值×0.8 + 新值×0.2` 当成永恒真理；v0.1 可用此方式起步，但必须保留原始证据以便替换算法。

## 6. 置信度分级

- `0.00–0.39`：探索性观察，不向用户给出稳定结论；
- `0.40–0.59`：候选模式，使用“可能”；
- `0.60–0.79`：中等证据，展示依据与限制；
- `0.80–1.00`：较强证据，仍允许用户纠正。

置信度不是模型自报一个数字，而应结合样本量、证据一致性、任务覆盖与用户反馈计算。

## 7. 用户可见性

“AI 对我的理解”页面应显示：

- 结论；
- 支持证据与反证；
- 置信度和时间范围；
- “准确 / 部分准确 / 不准确”；
- 修改说明、隐藏和删除入口。

不得显示未经解释的黑盒标签。

## 8. MVP 最小模型

第一版只实现：

- 每个概念的最近诊断与历史；
- 掌握等级与置信度；
- 误区标签及出现次数；
- 用户诊断反馈；
- 一个基于证据的简单趋势。

能力、思维模式和学习偏好先作为实验字段，不参与高影响推荐。

## 9. 禁止推断

- 心理健康、智力、人格、道德或职业适配的确定性判断；
- 从停顿、用时或一次退出推断动机；
- 从单学科表现推断整体能力；
- 将相关行为解释为因果；
- 将模型输出当作事实覆盖用户自述。

## 10. 质量问题

评估认知模型时必须问：

1. 结论能否追溯到原始证据？
2. 是否混淆知识状态和表达能力？
3. 是否展示反证和不确定性？
4. 用户纠正后系统是否真正更新？
5. 结论是否能改变一个具体学习决策？
6. 删除用户数据后，派生画像是否一并删除？
